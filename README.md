## Welcome to Our Senior Design Project!

### Hardware

Put some base organization, hardware files in general should be put into the overall hardware folder unless:

- Microcontroller, should go into a designated section of software rather (TBD)
- Finalized circuits, hardware spec docs, and fabric designs (and others TBD) have specific hardware sub-folders

### Software

This folder includes our work on everything in our software stack. We have our code for our ESP32 handling BLE communication, IOS app code, our frontend website, and our backend api.

### Citations
We use a third party library that has been included into our repository because it was the only way to upload our work to the phone that we are developing on without deploying it. The library is called Alamofire, it's used for HTTP communication in Swift. You can find it at Software/BLE-IOS/Alamofire
